1. Getting started

The editor is a static page — no build step, no server-side logic. Serve the sprite/ directory over HTTP (or open the editor from any HTTP server rooted above it) and visit editor/.

The runtime it depends on is the sibling file sprite.js at the repo root, loaded as a plain script. Everything else is ES modules inside editor/.

A typical session

  1. Open the editor.
  2. File → Load Sprite… and pick a sheet's JSON (e.g. hero.json).
  3. The editor will ask separately for the sheet's image. Pick it (e.g. hero.png).
  4. Click a frame in the left sidebar to select it. The viewport pans and zooms to it.
  5. Pick a tool, choose a colour, and paint.
  6. When you're done: File → Save Image and File → Save Sprite Data, or Save All to write both at once.

The editor tracks two independent "dirty" states — one for the image, one for the sprite data — so you can edit and save either half without touching the other. The dot in the status bar tells you which is pending.

2. The layout

The interface is a fixed three-column grid with a toolbar on top and a status bar at the bottom.

Toolbar

From left to right: the File, Edit, Sheet, View, and Transform menus; Undo and Redo; the Filter button; then Fit, zoom-out, zoom-in, and a percentage readout.

Left sidebar

Two tabs — Frames and Sequences — each with a list and a small action bar. Below them, a live Preview of the current sequence.

Centre

The atlas viewport fills most of the space. Below it, the Timeline shows thumbnails of the selected sequence.

Right sidebar

Two tabs — Image and Sprite. The Image tab holds Colours, Tools, and the Brush / Tool sub-tabs. The Sprite tab holds the Frame, Sequence, and Collision inspectors.

Status bar

Left to right: an unsaved-changes dot, the status message, an image notice (when the image is missing or mismatched), and the pixel coordinate under the cursor.

3. Loading and saving

File menu

ItemShortcutAction
New SpriteCtrl+Alt+NOpen a dialog to create a fresh sheet with a blank image and a set of empty frames.
New Image—Replace the current image with a blank canvas of a chosen size, keeping the sheet's frames and settings.
Load Sprite…—Pick a sheet JSON from disk.
Load Image…—Pick an image file from disk. Replaces the current image only.
Save ImageCtrl+SWrite the current image as a PNG.
Save Sprite DataCtrl+Shift+SWrite the sheet's JSON.

Save Image As…—Prompt for a filename, then write the image.
Save Sprite Data As…—Prompt for a filename, then write the JSON.

The sprite and image are independent. Loading a sprite while an image is already loaded keeps the existing image; loading an image replaces the image only. Loading either from a fresh session — with nothing else loaded — bootstraps the other with sensible defaults.

Where files go

In browsers that support the File System Access API (Chrome, Edge, Brave), the first save prompts for a directory. Subsequent saves to the same directory happen silently. In other browsers (Firefox, Safari), saving triggers a download as usual. The Save As variants always prompt for filenames.

Image notices

If the sprite's declared image filename doesn't match what's loaded, or no image is loaded at all, the status bar shows a small notice with a Load… link.

Dirty tracking

The status dot lights when the current state differs from the last save. Hover it to see which half is dirty. Undoing back to the saved state clears it — the editor compares the current undo-stack position to the one recorded when you last saved.

4. Frames

Frames are the unit of both drawing and animation. Each has a rectangle on the atlas, an origin (centerx/centery), and optional per-frame collision.

Selecting

  • Click a frame to select it. The viewport pans and zooms to it.
  • Ctrl-click (or Cmd-click) to add or remove a frame from the selection.
  • Shift-click to select a contiguous range from the previous click.

Bulk operations act on the whole selection. The primary selection — the last frame clicked — is what the inspectors and drawing tools act on.

Action bar

ButtonAction
+Create a new blank frame at the first free slot in the atlas.
⧉Duplicate the selected frame (or all selected frames, if multi-selected).
×Delete the selected frames.
↑, ↓Move the selected frames up or down one position in the list.

Renaming

Double-click a frame's name. Enter commits, Escape cancels. Renaming a frame updates every sequence that references it.

Right-click menu

New blank frame / Duplicate / Delete.

Frame inspector

On the Sprite tab, the Frame pane shows Name and the six numeric fields: x, y, width, height, centerx, centery. Edits apply immediately and are undoable.

5. Sequences

A sequence is an ordered list of frame names with a playback rate. Sequences are edited in the Sequence inspector on the Sprite tab.

Creating and deleting

The + button in the Sequences action bar creates a new sequence named after the currently-selected frame (e.g. seq_idle). Right-click a sequence to delete it.

Editing

FieldMeaning
NameRename via double-click in the list or by editing this field.
frameRateFrames per second. Used when frameTimes is blank.
iterations0 loops forever. 1 plays once. n plays n times.
frameTimesOptional comma-separated per-frame durations in milliseconds. Overrides frameRate when non-blank. The ⟳ button fills it with the uniform frame rate.

Below the numeric fields, the frames list shows the sequence's frames in order. Use the arrow buttons to reorder, × to remove, and + Add current frame to append the currently-selected frame.

Frame times are positional, not attached to specific frames. Reordering the frames list does not reorder the timings — frameTimes[0] always applies to whatever frame is first.

6. Timeline

The timeline strip below the viewport shows a thumbnail for every frame in the selected sequence, in order.

  • Click a tile to select that frame. Clicking an already-selected tile zooms to it.
  • Drag a tile left or right to reorder the sequence. One drag is one undo step.

The index badge on each tile shows its position in the sequence.

7. Preview

The Preview pane at the bottom of the left sidebar runs the selected sequence through the actual sprite.js runtime, so what you see is what the game will render.

ControlMeaning
⏸ / ▶Pause or play. Pausing freezes on the current frame; selecting a different frame while paused updates the display.
LoopWhen checked, a finite sequence restarts automatically instead of stopping at its last frame.
StatusShows the current frame name and its index within the sequence.

Selecting a sequence always starts playing. If a sequence runs to completion (with Loop off), the button flips to ▶ so you can tell it finished rather than paused.

8. Tools

Tools live on the Image tab's Tools grid. The currently-active tool is highlighted. Each has a single-letter shortcut.

ToolKeyBehaviour
SelectS Drag to define a rectangular selection. Click without dragging to clear. Ops that target a frame act on the selection when there is one.
PanP Drag to pan. Middle-drag pans with any tool active.
PencilN Freehand drawing. Left button paints primary, right paints secondary.
AirbrushA Accumulative — the longer you dwell, the more opaque the deposit. Has a Flow setting.
EraserE Fades pixels to transparent. Has an Opacity setting.
LineL Drag to draw a line. Preview follows the cursor.
BoxB Drag to draw a rectangle. Uses the Fill toggle.
OvalO Drag to draw an ellipse fitted to the bounding box. Uses the Fill toggle.
FillG Flood-fill the connected region of similarly-coloured pixels.
PickI Eyedropper. Samples the pixel under the cursor into the palette, including alpha.
FrameM Drag the selected frame's rect. Shift-click another frame to swap positions and contents. Has a Move contents setting.
HitK Edit collision circles. Drag to move or create; right-click to delete. Has an Always show setting.

Tool options

Fill and Clip checkboxes sit below the tool grid. Fill affects the Box and Oval tools. Clip confines strokes to the selected frame's rect — with it off, you can draw across frame boundaries.

Tools with their own settings expose them under the Tool sub-tab next to Brush. The panel rebuilds when you change tools.

Cell-change guard

With Clip on, a click that lands in a different frame selects that frame and stops there — the tool's gesture is deferred to the next click. This prevents accidental collision circles or paint strokes when you meant to switch frames. Pan, Pick, Select, and Frame are exempt.

Ctrl-to-sample

Hold Ctrl (or Cmd) to temporarily turn any tool into an eyedropper. Left-click samples into primary, right-click into secondary. Releasing the key returns to the previous tool.

9. Colours and alpha

Two colour slots: Primary for the left mouse button, Secondary for the right. Below them, a Recent strip (last 16 colours used) and a fixed palette of presets.

Choosing a colour

  • Click a swatch to open the picker: SV square, hue strip, hex field, and an alpha slider.
  • Left-click a recent or preset to set primary.
  • Right-click one to set secondary.
  • Swap with the ⇄ button or by pressing X.

Alpha is part of the colour — a semi-transparent red and an opaque red are different entries. Recents preserve whatever alpha they were chosen with; presets always set alpha to 255. Sampling a pixel with the Pick tool copies both the colour and its alpha.

10. Brushes

The Brush sub-tab holds eight brush shapes. Each is a small mask of weights; the preview shows the shape at a consistent scale so you can compare sizes at a glance.

BrushShape
pixelA single pixel.
crossA 3×3 plus shape.
square2A 2×2 solid square.
square3A 3×3 solid square.
circle3A 3×3 ring.
circle5A 5×5 circle.
soft3A 3×3 with weighted edges (darker at the corners, solid in the centre).
soft5A 5×5 with a smooth falloff to the edges.

Weights matter for the Airbrush and Eraser — soft brushes feather at the edges rather than cutting off sharply. The Pencil, Line, Box, and Oval ignore them and stamp at full opacity.

11. Filters

Filter… in the toolbar opens a floating panel with a matrix-based convolution. It applies to the selection if there is one, otherwise to the whole frame.

The matrix

A square grid of numbers that is convolved with the region. Size can be toggled between 3×3 and 5×5. Presets include several blur, sharpen, emboss, and edge variants; each can be edited freely after selection.

Controls

FieldMeaning
DivisorDivides the weighted sum. Usually set to the sum of the matrix so overall brightness is unchanged. Blur kernels need this; edge and emboss kernels typically don't.
OffsetAdded after the division. Useful for edge detection where the weighted sum can go negative.
Convolve alphaWhen off, alpha passes through unchanged so hard edges stay hard. When on, alpha is convolved like the colour channels, producing soft edges.

Pixels near the region's boundary are clamped to the nearest in-bounds pixel, so a filter on one frame never reads into a neighbouring frame.

The preview overlays the result on the atlas. Apply writes the pixels and pushes a single undo entry. Cancel discards.

Arbitrary rotation

Transform → Rotate… opens a floating panel with an angle slider (wrapping between −180° and +180°) and a numeric entry for values outside that range.

The Pivot section has two number fields and two preset buttons. Pivot coordinates are region-relative: (0, 0) is the top-left of the region being rotated.

PresetEffect
Selection centrePivot at the region's geometric centre — the default when the panel opens.
Frame centrePivot at the frame's origin (its centerx/centery), expressed relative to the region.

Custom values outside the region are allowed — rotating around a point off the sprite is occasionally useful.

Rotation uses nearest-neighbour sampling, which is what you want for pixel art: bilinear would introduce colours that don't exist in the source. Small angles will look chunky; that's inherent to the approach.

Rotating by 0° (or 360°, or any multiple) is detected as a no-op and does not create an undo entry.

13. Collision

Collision is per-frame. Each frame has zero or more circles, each with an offset from the frame's origin and a radius. A frame with no circles simply has no collision.

Edit them in the Collision pane on the Sprite tab, or with the Hit tool directly on the canvas.

Hit tool gestures

  • Drag on empty space — creates a new circle, growing from the press point.
  • Drag inside an existing circle — moves it.
  • Right-click a circle — deletes it.

Inspector

Each circle has three fields: offsetX, offsetY, radius. A + Add circle at origin button appends a new one sized to the frame. The × button on each row removes it.

The Copy to all frames button writes the current frame's collision onto every other frame in the sheet as one undoable step. Useful when you've tuned a shape and want it applied consistently across an animation.

Overlay

Collision circles are drawn over every frame in the sheet when the overlay is on. The selected frame's circles draw at full strength; the rest are dimmed. The Always show checkbox in the Tool sub-tab controls whether they're visible when the Hit tool isn't active. With Hit active, the overlay is always on.

14. Sheet settings

Sheet → Sheet settings… opens a dialog for the sheet-wide defaults.

FieldMeaning
Image size (W/H)Resizes the canvas. Expanding adds blank space at the right and bottom; shrinking crops. Shrinking is allowed; frames that extend past the new bounds keep their data but lose pixels outside.
Frame width/heightDefault tile size. Affects new frames and the col/row shorthand. Existing frames keep their own dimensions.
Centre X/YDefault origin for new frames.
Image fileThe filename recorded in the sheet's JSON. Change it if you renamed the PNG on disk.
Frame rateDefault frame rate for new sequences.

Shrinking the canvas past a frame's bounds keeps the frame's data — its x, y, and dimensions are unchanged — but any pixels outside the new canvas are gone. The dialog warns before applying if any frame would be affected.

Changing the image size and any other field at the same time is one undo step.

15. Reshape

Sheet → Reshape… repacks every frame into a clean row-major grid and resizes the canvas to fit. Cells use the sheet's current frameWidth/frameHeight.

The dialog asks for a column count and shows the resulting grid and canvas size live. A suggested column count that produces a roughly square layout is pre-filled. The canvas is resized to exactly fit — no wasted space at the right or bottom.

Frame order is preserved: frames fill the grid left-to-right, top-to-bottom, in the order they appear in the frame list. Frames larger than a single cell get clipped to the cell size; the dialog lists them.

Reshape is one undo step. The old canvas is preserved for the undo, so reverting restores both the previous layout and the previous image exactly.

16. View options

The View menu controls how the atlas is presented, without touching any data.

ItemEffect
Background…Opens a popover for the canvas backdrop. Choose a texture (Checker, Dots, Stripes, None) and two colours.
Show gridToggle a faint grid at frameWidth/frameHeight spacing. Hidden automatically when zoomed out below 3× so it doesn't clutter the view.
Snap to gridWhen on, the Frame tool's drags snap to the grid. Other tools are unaffected.

The background is a good way to check sprites with colours that are hard to distinguish against the default checkerboard. Two independent colours let you tune contrast to the artwork.
